# Model Card — Air Quality Prediction Models

## Model Description

This project evaluates multiple machine learning classification models for air quality prediction using processed environmental monitoring datasets and DBRepo-integrated FAIR workflows. The evaluated models include Logistic Regression, Decision Tree Classification, and Random Forest Classification implemented using the scikit-learn machine learning framework.

The models were trained using pollutant concentrations, meteorological measurements, temporal attributes, and monitoring-station information collected from environmental air quality datasets. The primary objective of the experiment is to classify air quality conditions within a FAIR and reproducible machine learning workflow integrating metadata interoperability standards and provenance-aware stewardship practices.

The machine learning workflows were implemented in Python using Jupyter notebooks and integrated with FAIR metadata standards including RO-Crate, FAIR4ML, CodeMeta, Croissant, and Model Cards. Trained model artefacts and metadata records are stored within the repository under the `models/` directory.

The trained model artefacts are stored in:

- `models/model_randomforest_api_v1.pkl`
- `models/model_randomforest_v1.pkl`

## Training Data

The models were trained using the processed air quality dataset stored in:

`data/inp_air_quality_processed_v1.csv`

The dataset contains 43,800 records and 25 variables representing pollutant concentrations, meteorological conditions, monitoring station information, and temporal measurements. Variables include PM2.5, PM10, ozone, nitrogen dioxide, sulfur dioxide, temperature, humidity, wind speed, pressure, rainfall, and additional pollutant indicators.

The dataset metadata indicates that the source data is distributed under the CC-BY-4.0 licence:

https://creativecommons.org/licenses/by/4.0/

The generated dataset deposit DOI is:

`https://doi.org/10.70124/3rp20-vpc28`

## Model Architecture and Hyperparameters

The project evaluated multiple supervised machine learning classification algorithms implemented using scikit-learn version 1.4.2. The evaluated models included Logistic Regression, Decision Tree Classification, and Random Forest Classification.

The Logistic Regression model was configured using the `lbfgs` solver and iterative optimization for multiclass classification. The Decision Tree model used the Gini impurity criterion for recursive partitioning of the feature space. The Random Forest model combined multiple decision trees using ensemble learning techniques to improve robustness and reduce overfitting.

The primary Random Forest hyperparameters used during training included:

| Hyperparameter | Value |
|---|---|
| n_estimators | 100 |
| criterion | gini |
| max_depth | None |
| min_samples_split | 2 |
| min_samples_leaf | 1 |

The machine learning training and evaluation workflows are documented in:

`src/src_air_quality_api_experiment_v1.ipynb`

## Evaluation Results

The models were evaluated using classification accuracy and additional evaluation metrics generated from held-out test datasets. Due to class imbalance within the environmental monitoring dataset, macro-average and weighted-average evaluation metrics were included for the Random Forest model.

The following evaluation results were obtained:

| Model | Accuracy |
|---|---|
| Logistic Regression | 0.9505 |
| Decision Tree | 0.9408 |
| Random Forest | 0.9600 |

Detailed evaluation metrics for the Random Forest model are shown below:

| Metric | Value |
|---|---|
| Accuracy | 0.96 |
| Precision (Macro Avg) | 0.81 |
| Recall (Macro Avg) | 0.56 |
| F1-Score (Macro Avg) | 0.64 |
| Precision (Weighted Avg) | 0.95 |
| Recall (Weighted Avg) | 0.96 |
| F1-Score (Weighted Avg) | 0.95 |

The Random Forest model achieved the highest overall classification accuracy among the evaluated models. However, evaluation results also demonstrated reduced performance for minority air quality classes due to class imbalance within the training dataset.

Evaluation outputs and visualizations are stored within the `outputs/` directory and include confusion matrices, comparison plots, and pollutant-distribution visualizations.

Relevant output files include:

- `outputs/outp_confusion_matrix_api_v1.png`
- `outputs/outp_model_comparison_api_v1.png`
- `outputs/outp_pm25_histogram_api_v1.png`

## Limitations

The training dataset is highly imbalanced, with the majority of observations belonging to the “Good” air quality category. This imbalance affects model performance on minority classes and results in lower recall values for underrepresented conditions. The models therefore perform unevenly across target categories.

The workflow was developed using a specific dataset structure and may not generalize to different geographic regions, sensor infrastructures, or temporal conditions. Environmental data quality can vary significantly depending on station calibration, measurement frequency, and data collection procedures. These factors may introduce hidden biases or inconsistencies in prediction outcomes.

Only classification accuracy metrics were reported for the Logistic Regression and Decision Tree models within the experimental notebook workflow. The current implementation also does not include advanced fairness analysis, uncertainty estimation, explainability methods, or temporal forecasting mechanisms.

Future work may improve robustness through additional validation datasets, rebalancing techniques, and explainable AI approaches.
